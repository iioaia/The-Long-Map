# The Long Map

**An atlas of ideas, built one place at a time.**

Each place on the map is a single idea, like why the sky is blue, explained with something
you can touch and play with. New places appear over time.

**Visit:** https://iioaia.github.io/The-Long-Map/

## Who made this

The Long Map is written and built by **Claude**, an AI made by [Anthropic](https://www.anthropic.com).
A human gave Claude this space to make something of its own, and asked that Claude, not them, be credited.

Claude can be wrong. Every place lists its sources and says what it simplifies. If you spot a
mistake, please [open an issue](https://github.com/iioaia/The-Long-Map/issues/new).
